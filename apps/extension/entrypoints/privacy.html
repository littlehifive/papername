Papername beta privacy

Papername reads bibliographic metadata on HTTP(S) pages solely to name the academic PDF you download. Automatic coverage across publishers, university proxies, and institution-specific repositories requires broad Chrome site access, which Chrome discloses at install or update.

Local presets

Citation and title filenames are generated entirely in your browser. Papername does not inspect your Downloads folder or retain a download library.

Site access

Page metadata is processed locally and retained only as a short-lived article context. Papername does not modify pages. On unrecognized sites, it watches only citation metadata in the document head; tested academic sources may also expose metadata elsewhere in the page. You can change Papername to “On click” or selected sites, or disable its access, through Chrome's extension Site access controls. Doing so reduces automatic coverage.

For a few recognizable repository PDF routes, an explicit action may retrieve the public article-record page from the same site. Papername does not read or upload the PDF itself. ResearchGate is excluded because its current terms prohibit this kind of browser-add-on access.

When you activate a Google Scholar side link marked “[PDF],” Papername reads the visible result title, author line, year, and selected link locally so that many library-proxy downloads can be matched. It does not automate searches, retain a search history, treat snippets as abstracts, or send Scholar result data to Papername's server.

Hosted gist preset

After explicit consent, Papername sends only a paper's title and abstract to the Papername API. It does not send the PDF, DOI, page URL, authors, or filename. The Papername backend does not persist the title, abstract, or generated gist.

If a page supplies a DOI but omits information needed for the gist, Papername may send that DOI to Crossref to fill the missing bibliographic fields. It does not send the PDF to Crossref.

The AI provider does not use API inputs to train its models by default. Under its standard controls, prompts and responses may appear in abuse-monitoring logs for up to 30 days.

Optional telemetry

If you opt in, Papername records aggregate counts for preset selection, rename outcome, fallback reason, latency bucket, and extension version. It does not include paper content, identifiers, URLs, filenames, or an installation identifier.

Beta access

Your invite is exchanged for a random access token. Only cryptographic hashes of invite codes and access tokens are stored. Monthly usage counts are attached to the token hash to enforce the beta allowance.
