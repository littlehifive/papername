# Issue tracker: Local Markdown

Papername's MVP is tracked in this repository rather than through external GitHub Issues.

## Conventions

- The canonical product requirement is `docs/PRD.md`.
- Follow-up work items may live under `.scratch/<feature-slug>/issues/`.
- A `Status:` line uses the labels defined in `docs/agents/triage-labels.md`.
- External pull requests are not a request surface unless the maintainer explicitly changes this policy.

When a skill asks to publish or fetch the current specification, use `docs/PRD.md`.
