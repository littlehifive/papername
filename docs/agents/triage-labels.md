# Triage labels

| Canonical role    | Local label       | Meaning                           |
| ----------------- | ----------------- | --------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer evaluation is required |
| `needs-info`      | `needs-info`      | Reporter information is required  |
| `ready-for-agent` | `ready-for-agent` | Fully specified and agent-ready   |
| `ready-for-human` | `ready-for-human` | Human-only action is required     |
| `wontfix`         | `wontfix`         | Work will not be actioned         |
